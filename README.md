# SQL-learning practice
Практичні SQL запити які я пишу в процесі навчання

## Інструменти:
- PostgreSQL 18
- pgAdmin 4
- DBeaver

## Бази даних:
- ds_salaries — датасет зарплат Data Science спеціалістів (https://www.kaggle.com/datasets/arnabchaki/data-science-salaries-2023)
- DBeaver Sample Database — вбудована тестова база даних DBeaver

## Теми:
- Базові запити: SELECT, FROM, WHERE, ORDER BY, LIMIT, DISTINCT, AS
- Фільтрація: AND, OR, IN, NOT IN, BETWEEN, NOT BETWEEN, LIKE, ILIKE, IS NULL
- Агрегатні функції: COUNT, SUM, AVG, MIN, MAX
- CASE WHEN THEN ELSE END
- Групування: GROUP BY, HAVING
- Вкладені запити (Subqueries)
